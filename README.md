# Florist

Florist is an open-source, Flourish-inspired starter app for generating dynamic and interactive visualizations with Next.js and D3.

## Features

- Next.js App Router foundation with TypeScript.
- D3-powered SVG charts rendered from React state.
- Interactive chart type, segment, and intensity controls.
- MIT license for open-source reuse.

## Getting started

```bash
npm install
npm run dev
```

Open <http://localhost:3000> to use the visualization studio.

## Scripts

- `npm run dev` starts the local development server.
- `npm run build` creates a production build.
- `npm run start` serves the production build.
- `npm run lint` runs Next.js linting.
